# AI Chatbot Demo

A simple AI-powered chatbot project built to demonstrate how AI APIs can be integrated into a web application using HTML, CSS, and JavaScript.

---

## Features

- Simple chatbot interface
- User message input and AI-generated responses
- AI API integration
- Responsive design
- Beginner-friendly project structure
- Easy to customize and extend

---

## Tech Stack

- HTML
- CSS
- JavaScript
- AI API
